# Red Light Green Light Analysis — Canadian Reference

## One-Sheet Scoring Model

Score each area 0 to 20 for a total of 100.

| Area              | What to Score                                                    |
| ----------------- | ---------------------------------------------------------------- |
| Financial quality | EBITDA quality, margin stability, working capital, capex realism |
| Deal structure    | DSCR, financing fit, seller flexibility, downside protection     |
| Transfer of value | Customer, employee, structural, social transferability           |
| Seller psychology | Motivation, urgency, distress, realism, trustworthiness          |
| Risk and friction | CRA, lease, licence, litigation, concentration, closing friction |

## Decision Rules

- 75 to 100: Green. Move to LOI or full diligence.
- 55 to 74: Yellow. Proceed only if the weak points are specifically fixable.
- Below 55: Red. Pass, or only pursue as a highly creative or staged deal.

## Fatal Red Flags

- Unresolved CRA liens or payroll remittance issues
- Seller hiding basic financial statements or tax returns
- No path to transfer key licence, lease, or contract
- Customer concentration so high one loss would break debt service
- Seller demands all cash at a premium multiple with no flexibility

## Yellow-But-Fixable Examples

- Owner-dependent but willing to stay 12 months
- Lease is short, but landlord is cooperative
- Books are messy, but accountant can rebuild quickly
- Margin compression is recent and clearly explained
- Seller wants price, but is open on terms

## Standard Output Format

1. Headline: Red, Yellow, or Green
2. Score out of 100
3. Top 3 reasons for the decision
4. Financing view
5. Best structure to pursue
6. Exact next action this week
