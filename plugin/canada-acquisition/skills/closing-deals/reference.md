# Closing Deals — Canadian Reference

## Full Closing Checklist

### Phase 1: Post-LOI Setup

- [ ] Sign NDA / Confidentiality Agreement
- [ ] Assemble deal team: M&A lawyer (province-specific), CPA, BDC/banker, broker if applicable
- [ ] Apply for CRA clearance certificate immediately (4–6 week lead time)
- [ ] Request full due diligence document package
- [ ] Confirm exclusivity start/end dates and build backward from close date

### Phase 2: Due Diligence

**Financial:**

- [ ] 3 years T2 returns + financial statements
- [ ] 12 months bank statements
- [ ] AR/AP aging, HST/GST filings, payroll remittance history
- [ ] CRA account status (no liens, no outstanding remittances)

**Legal:**

- [ ] Articles of incorporation + corporate records
- [ ] All contracts (customers, suppliers, employment)
- [ ] Lease agreements — confirm assignability
- [ ] PPSA searches for liens on assets (Canada-wide Personal Property Security searches)
- [ ] Corporations Canada / provincial registry search
- [ ] Any pending or threatened litigation

**Operational:**

- [ ] Facility walkthrough + equipment inspection
- [ ] Key employee conversations (with seller permission)
- [ ] Top customer reference checks
- [ ] Software systems and data inventory

### Phase 3: Financing

- [ ] Borrower package submitted to BDC / bank
- [ ] Site visit or management presentation completed (BDC usually requires)
- [ ] All lender conditions satisfied (track each one; respond same day)
- [ ] Commitment letter received
- [ ] Personal guarantee signed

### Phase 4: Purchase Agreement (drafted by Canadian M&A lawyer)

Key negotiation items:

- Representations and warranties (seller warrants accuracy of financials)
- Indemnification period and holdback (10–15% held 12–18 months)
- Working capital peg (prevent seller from stripping cash before close)
- Non-compete and non-solicitation terms
- CRA clearance certificate as closing condition
- Section 167 election (asset sale — no HST on going concern)
- Section 116 compliance (non-resident seller — withholding if applicable)

### Phase 5: Conditions Satisfaction

- [ ] Financing condition satisfied (lender commitment letter)
- [ ] Due diligence condition waived
- [ ] Landlord consent to lease assignment in writing
- [ ] CRA clearance certificate received
- [ ] Key employee retention agreements signed
- [ ] Regulatory licences transferable / re-issued in buyer's name

### Phase 6: Closing Day

- [ ] Funds wired to lawyer's trust account
- [ ] Share certificates transferred (share sale) or Bill of Sale executed (asset sale)
- [ ] Seller VTB promissory note signed
- [ ] Non-compete signed
- [ ] Transition services agreement signed
- [ ] New bank accounts opened; buyer added as signing authority
- [ ] CRA business number transferred or new one obtained
- [ ] HST account updated to buyer
- [ ] Insurance transferred to buyer's name
- [ ] All keys, access codes, software logins transferred
- [ ] Employee announcement (planned in advance with seller)

## Common Obstacles and Solutions

| Obstacle                             | Solution                                                       |
| ------------------------------------ | -------------------------------------------------------------- |
| Lender requests more documents       | Respond same day — never let lender requests sit               |
| CRA clearance delayed                | Apply week 1; have lawyer follow up with CRA directly          |
| Landlord won't approve assignment    | Negotiate directly; offer personal guarantee                   |
| Seller tries to renegotiate at close | Stay firm; document all prior agreements; lawyer intervenes    |
| Key employee threatens to leave      | Identify early; retention bonus tied to 12-month stay          |
| DD reveals undisclosed issue         | Renegotiate price reduction or increase holdback; don't ignore |
| Financing falls through              | Have backup lender identified; bridge with seller VTB          |
| Seller changes mind                  | Enforce exclusivity clause; lawyer sends notice                |

## First 72 Hours Post-Close

1. Announce to employees in person with seller present
2. Change all bank account signing authorities
3. Call top 5 customers personally — introduce yourself, reinforce continuity
4. Call key suppliers — introduce yourself, confirm payment terms
5. Review all outstanding payables and receivables
6. Set up biweekly operational meeting cadence
7. Begin transition handover schedule with seller

## Critical Path Compression Tips

- Apply for CRA clearance in week 1 every time
- Start landlord and licence conversations early, not after loan approval
- Give lenders a clean index of requested files rather than sending loose documents
- Track every closing condition in one sheet with owner and due date
